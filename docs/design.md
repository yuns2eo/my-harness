# design.md
> 우리 회사 브랜드전 배너 디자인 기준. 게이트 라운드(R5)에서 이 문서의 수치가 rules.yaml로 옮겨진다.
> 🚦 = 스크립트로 셀 수 있어서 게이트로 쓸 규칙. 표시 없는 건 사람이 보는 기준.

## 1. Overview
우리 회사 앱 홈에 나가는 브랜드 행사 배너. 제품과 반려동물 이미지가 주인공이고, 텍스트는 브랜드와 혜택을 빠르게 읽히게 하는 역할만 한다. 장식 없이 이미지 배경색과 프레임이 자연스럽게 이어지는 깔끔한 톤.

## 2. 규격
| 배너 | Figma 작업 크기 | export (3x) | 🚦 |
|---|---|---|---|
| 메인배너 | 375×200 | 1125×600 | 🚦 |
| 띠배너 | 1125×222 | 3375×666 | 🚦 |
| 리뉴얼배너 | 327×327 | 981×981 | 🚦 |

- 🚦 export는 3배수. 3배가 안 되면 최소 2배
- 원본 템플릿: Figma `${FIGMA_FILE_KEY}`, 배너 템플릿 섹션 `${TEMPLATE_SECTION_NAME}` (수정 금지, 통째로 복제해서 사용)

## 3. Colors
- 🚦 프레임 배경은 삽입 이미지의 빈 배경색에서 샘플링한다. 순백 `#FFFFFF` 금지
- 텍스트 색은 템플릿 값 유지 (기본 `#000000`). 임의 변경 금지
- 띠배너 버튼 레이어 색은 템플릿 값 유지

## 4. Typography
- 🚦 폰트는 Pretendard만. Inter 등 대체 폰트 금지
- 예외: 띠배너 `바 로 가 기` 라벨은 Sandoll GothicNeo1 그대로 두고 절대 수정하지 않는다
- 🚦 폰트 크기, 굵기, 행간, 자간은 템플릿 값에서 바꾸지 않는다 (텍스트 내용만 교체)
- 🚦 메인배너 `#M_main_text`는 최대 3줄, 의미 단위로 직접 줄바꿈
- 🚦 한글은 어절 중간에서 줄바꿈되지 않는다. 자동 줄바꿈에 맡기지 않고 `\n`으로 직접 끊는다
- 🚦 작성 문구에 가운뎃점 `·` 사용 금지 (`&` 사용). 여러 브랜드는 `A&B&C`

## 5. Layout & Shapes
### 메인배너 (375×200)
- 🚦 `#image` 슬롯: X141 / Y-34 / W234 / H234
- 🚦 피사체 높이 170~175, 상하 여백 15 내외
- 🚦 동물 얼굴은 x216 왼쪽 (그라데이션 시작점에 가리면 실패)
- 텍스트 오른쪽 끝(x169)과 피사체 사이 여유

### 띠배너 (1125×222)
- 🚦 피사체 높이 185~190, 상하 여백 18 내외
- 🚦 피사체는 로고 끝(x325)과 문구 시작(x580) 사이
- 로고 인스턴스 128×128

### 리뉴얼배너 (327×327)
- 🚦 피사체 높이 165~180, 상단 문구(y120) 아래부터, 가로 중앙

### 공통
- 🚦 피사체 좌우 여백은 피사체 폭의 5% 이상. 동물, 그릇, 제품이 잘리면 실패
- 🚦 이미지와 배경 사이 세로 경계선 없음 (인접 열 평균색 차이 10 미만)
- 🚦 브랜드명과 혜택 박스가 겹치지 않는다 (혜택 x = 브랜드명 x + 폭 + 8~10)
- 여백 넉넉히, 정렬과 간격 통일, 한쪽으로 치우치지 않게 (시각보정 완료 상태로 넘긴다)

## 6. Components
- 🚦 이미지는 마스크 그룹 금지. 프레임(슬롯) 안에 이미지 fill로 넣고 원본 비율 유지, 프레임이 잘라준다
- 🚦 로고 레이어명은 `logo`, `logo_2`… 요청 브랜드의 logo variant 인스턴스만 사용 (사각형 복사 금지)
- 아이콘이 필요하면 직접 그리지 않고 Iconify에서 가져온다
- 🚦 레이어 네이밍: `{제작일YYMMDD}_{작업명}/{제작일}_{작업명}_{메인배너|띠배너|리뉴얼배너}{_강|_고}`
- 🚦 export 파일명: `{제작일}_{작업명}_{배너종류}{_강|_고}.png` (`@3x` 접미사 없음)

## 7. Do's and Don'ts
### Do
- 제품을 충분히 크게, 동물 얼굴은 선명하게 보이게
- 템플릿 흰색 그라데이션 대신 프레임 배경을 이미지 배경색으로 통일
- 이미지가 프레임을 못 덮어 생긴 빈 영역은 `__bg_extend_{방향}` 레이어로 메운다
- GPT 이미지는 원본 파일 바이트로 넣는다

### Don't
- 🚦 화면 캡처로 이미지를 반입하지 않는다 (업로드 바이트 수 = 원본 바이트 수)
- 제품 라벨과 포장 디자인을 바꾸지 않는다
- 원본 배너 템플릿 섹션을 수정, 이동, 이름 변경하지 않는다
- 배너를 개별 복제하지 않는다 (섹션 통째로)
